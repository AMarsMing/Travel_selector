# Travel Selector · 出门不纠结

聚会出行决策器 —— 输入人数、预算、距离、时段等条件，从「不知道玩什么、吃什么」到快速定下来。

## 功能

- **条件筛选**：城市（支持成都各区县 / 四川其他城市）、区域、人数、人均预算、可接受距离、时段、天气、室内外偏好
- **玩法库**：21 种聚会玩法（公园露营、绿道骑行、Citywalk、逛展馆、桌游、KTV、剧本杀、密室、DIY、汤泉、室内滑雪、麻将棋牌、爬山、皮划艇、漂流、猫咖等），按条件自动筛选
- **美食库**：10 类川渝特色餐饮，带区域口碑店参考（营业状态与评分以高德/美团实时为准）
- **随机推荐**：每次「帮我推荐」/「换一批」随机抽取一批候选，次次不同
- **决策机制**：
  - 玩法、美食**两个独立抽签池**，一键抽签定夺
  - **投票 + 实时票况榜**：投一票/取消投票，底部同步显示票数排行
  - 排除不喜欢的候选，可随时恢复
- **自定义扩展**：可手动添加玩法/美食（本地保存，刷新不丢），参与投票和抽签
- **高德联动**：每个候选一键跳转高德搜索附近店（搜索词自动带上城市与区域）

## 使用

直接用浏览器打开 `出门决策器.html` 即可，无需安装、无需联网（字体走 CDN，无网络时自动回退系统字体）。

数据与状态仅保存在本地浏览器（localStorage），不出本机。

## 技术说明

- 单文件自包含 HTML（内联 CSS / 原生 JS），无任何构建依赖
- 无后端，纯前端本地运行
- 玩法与美食数据为通用建议，具体店铺信息请以高德 / 美团实时信息为准
